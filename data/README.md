# Data

Raw data is **not** stored in this repository. The files are large (≈0.35 GB and ≈1.6 GB)
and are owned by Monash University (Smart Infrastructure), supplied to MMA3001 students
for this assessment only.

## Required files (place in `data/raw/`)

| File | Contents |
|---|---|
| `5EnvSensor_MayToDec2024_180kRows.csv` | Environmental sensor uploads; one JSON payload per row |
| `Sensor_ID_and_Locations.xlsx` | Sensor ID → building / room / area lookup (sheet `ENV`) |
| `5occupancySensor_MayToDec2024_9MRows.zip` | Occupancy events (optional; kept zipped, read directly) |

Obtain them from the MMA3001 Moodle page ("Project Information – Dataset 2").

## Processed data (`data/processed/`)

Generated by `python scripts/01_build_clean_dataset.py`. Not committed; fully reproducible
from the raw files.
